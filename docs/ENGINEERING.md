# Model 3 工程示意範圍

本專案是可互動的 2024+ Model 3 雙馬達 AWD **概念展示**，不是 Tesla 原廠 CAD、維修資料或車輛認證模型。畫面座標以公尺近似 1:1 外觀比例，不能用來檢查板件公差、安裝間隙或碰撞安全。目標車型與市場必須保持一致；真車規格會依年份、地區、配備和軟體改變。

## 可核對的官方資料

- Tesla [2024+ Model 3 車主手冊（台灣英文版，Dimensions）](https://www.tesla.com/ownersmanual/model3/en_tw/Owners_Manual.pdf) 列出長續航版本車長 4,720 mm、車寬 1,850 mm（不含後視鏡）、車高 1,440 mm、軸距 2,875 mm、前後輪距約 1,584 mm，並明示數值為近似且因選配而變。
- Tesla [Electric Vehicle Components](https://www.tesla.com/ownersmanual/model3/en_us/GUID-8FA15856-1720-440F-838B-ACFBA8D7D608.html) 列出雙馬達車型的前馬達、後馬達、高壓電池、高壓線與充電埠。
- Tesla [Subsystems](https://www.tesla.com/ownersmanual/model3/en_us/GUID-E414862C-CFA1-4A0B-9548-BE21C32CAA58.html) 描述 AWD 前感應馬達、後永磁同步馬達、單速固定齒比、前雙 A 臂及後多連桿懸吊。手冊所示 9.03:1 齒比不等同本展示所用的整數 9:1 假設。
- Tesla [Regenerative Braking](https://www.tesla.com/ownersmanual/model3/en_us/Owners_Manual.pdf) 說明再生煞車由車輛減速回充電池，能力受電池溫度及電量限制；摩擦煞車可補足減速。展示中的負功率代表馬達回充，卡鉗本身不發電。
- Tesla [About Self-Driving](https://www.tesla.com/ownersmanual/model3/en_co/GUID-101D1BF5-52D2-469A-A57D-E7230BBEE94B.html) 明示功能隨市場、製造日期、硬體、選配與軟體而異。電腦與攝影機造型因此只能代表感測系統概念，不能標定為每輛車同一硬體代次。

## 展示與假設

外觀參考使用者指定的 [Tesla 台灣 Model 3 官網](https://www.tesla.com/zh_tw/model3)。精細外觀使用 RBLXSupercars 創作、brandonleong28 分享的 Highland 模型（CC BY 4.0），不是 Tesla 原廠資料。來源及修改均載於 [資產紀錄](../public/models/highland/CREDITS.md)。18 個可映射的外觀／座艙零件由原始連通元件分組；其餘工程零件採程序化模型，整體目錄共 43 個組件。

座艙保留原始左駕配置；外型參考不代表已驗證完整台灣量產配備。原始後廂蓋及充電蓋與其他曲面合併，保持精細外型完整；獨立開合採透明車殼中的機構示意。展示不宣稱每個鈑件均有精確原廠鉸鏈。

`src/catalog.ts` 的所有零件均標 `provenance: illustrative`，材質欄標「示意」。即使個別尺寸引用官方手冊，零件曲面、內部布局、材料牌號、電芯化學與包裝、線束走向、熱管理閥體及座艙裝配並沒有逐件 CAD 或 BOM 證據。電池視覺陣列只採**單一可配置圓柱電芯外觀**；它沒有同時宣稱 LFP 與 2170 為同一輛車的原裝電池。駕駛輔助電腦也不會同時宣稱 HW3 與 HW4 為同車配備。不要將 Model Y 的壓鑄後車體套作 Model 3 的既定構造。

`src/physics.ts` 的單軸縱向模型以 1,900 kg 車重、0.335 m 車輪半徑、9:1 齒比、75 kWh 可用容量、350 kW 驅動上限、75 kW 回充上限、固定空阻與滾阻作**教學假設**。它以速度計算轉速，以驅動與煞車力更新速度，用功率積分更新 SOC。速度不為負，暫停不推進；步長最多 0.25 秒。它不表示某一 VIN 的馬力、能耗、電池容量、回充曲線、0–100 km/h 成績或真實熱管理行為。煞車中的回充只是假設可回收的部分動能，忽略電池/馬達詳細限制；低速與滿電仍需摩擦煞車。冷卻粒子只表達流向，不是 CFD。熱度數值也非熱傳求解。

Ackermann 轉角使用 2.875 m 軸距與 1.584 m 前輪距。場景車頭為 +x、上方為 +y、左側為 -z；正轉角向左。左右前輪角從輸入的**路輪**角計算；方向盤採示意倍率，懸吊控制臂與彈簧隨設定的位移做幾何連動。轉向機非線性、輪胎側偏和懸吊受力未建模，不能驗證實車操縱性。

## 可交付範圍與工業級差距

目前可交付的是零件查詢、分系統視覺、互動控制及近似動力/能量遙測的瀏覽器展示。工業級數位孿生尚需授權 CAD 與測量、製造公差與版本管理、剛體/輪胎/懸吊求解器、經驗證的電池與熱模型、CFD、碰撞與安全認證資料，以及實車數據對照。HDRI、光追和精細 PBR 可以改善外觀，不能補足幾何與物理證據。影格率與裝置相依，任何性能目標都需指定硬體、解析度、場景負載和實測方法，不能保證固定 FPS。

若日後擴充，現有 Three.js/WebGL 路線適合可控的零件與互動展示；Three.js/WebGPU 可探索較大量粒子或運算，但需瀏覽器相容性回退。Babylon.js 與 PlayCanvas 皆可作完整網頁 3D 應用候選，選擇取決於團隊工具鏈與資產流程；Unreal 串流可提供更高視覺上限，但需伺服器 GPU、串流延遲及營運成本。任何路線仍須先取得合法且可驗證的車輛資料。
